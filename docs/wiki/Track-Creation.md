# Track Creation Guide

Learn how to create and optimize tracks in Beatmaker Legend's DAW system.

## DAW Track Creator Overview

The track creator is your primary tool for producing music. Each track is defined by multiple parameters that affect its performance in the game.

---

## Track Parameters

### Core Stats

| Parameter | Range | Description |
|-----------|-------|-------------|
| **BPM** | 60-200 | Tempo in beats per minute |
| **Energy** | 1-100 | Intensity and power of the track |
| **Groove** | 1-100 | Rhythmic feel and catchiness |
| **Sound Design** | 1-100 | Quality of synthesized sounds |
| **Mixing** | 1-100 | Production polish and balance |
| **Originality** | 1-100 | Uniqueness of the track |
| **Catchiness** | 1-100 | Memorable quality for listeners |
| **Danceability** | 1-100 | Club-readiness and movement |
| **Complexity** | 1-100 | Technical and compositional depth |

### Quality Calculation

Track quality = weighted average of all parameters:

```
Quality = (Energy × 0.15) + (Groove × 0.12) + (SoundDesign × 0.12) + 
          (Mixing × 0.15) + (Originality × 0.10) + (Catchiness × 0.12) + 
          (Danceability × 0.12) + (Complexity × 0.08) + (BPM_modifier × 0.04)
```

**BPM Modifier:** Higher BPM within genre range = slight bonus

## Stem System

Each track is composed of 5 stems that can be individually customized:

### 1. Beat Stem 🎧
- Drums and percussion
- Foundation of the track
- Influences Groove and Danceability

### 2. Bass Stem 🎸
- Low-frequency elements
- Drives the energy
- Influences Energy and Sound Design

### 3. Synth Stem 🎹
- Melodic content
- Lead sounds and pads
- Influences Originality and Catchiness

### 4. FX Stem ✨
- Sound effects
- Transitions and atmospheres
- Influences Complexity and Mixing

### 5. Vocals Stem 🎤
- Vocal elements (if present)
- Optional stem
- Adds catchiness if used well

### Stem Quality Boost

Upgrading gear provides stem-specific bonuses:
- **Vintage Drum Composer 909**: +15% Beat stem
- **Fat-Bass Analog Monosynth**: +10% Bass stem
- **Eurorack Modular**: +20% all stems

## Genre-Specific Tuning

### Techno
**Focus:** Sound Design, Energy, Mixing
**Avoid:** Overly complex arrangements
**Tip:** Keep it minimal but powerful

### Trance
**Focus:** Catchiness, Originality, Danceability
**Avoid:** Too dark or aggressive
**Tip:** Build memorable melodic hooks

### House
**Focus:** Groove, Mixing, Catchiness
**Avoid:** Too experimental
**Tip:** Emphasize warmth and soul

### Drum & Bass
**Focus:** Complexity, Energy, Sound Design
**Avoid:** Lazy bass design
**Tip:** Technical precision is key

### Synthwave
**Focus:** Originality, Catchiness, Mixing
**Avoid:** Cliché sounds
**Tip:** Balance retro with modern

## Gear Synergy

### Matching Gear to Genre

| Genre | Recommended Gear |
|-------|------------------|
| **Techno** | Eurorack Modular, Studio Headphones |
| **House** | FM Synthesizer, Studio Headphones |
| **DnB** | Drum Composer 909, Modular |
| **Synthwave** | Analog Monosynth, FM Synth |

### Upgrade Priority

1. **Headphones** ($190) - Always first, improves mixing
2. **FM Synth** ($450) - Sound design boost
3. **Drum Composer** ($1,200) - Beat quality
4. **Modular** ($3,200) - Ultimate upgrade

## Release Strategy

### Quality Thresholds

| Release Type | Minimum Quality |
|--------------|-----------------|
| Self-release | 50 |
| Label signing | 65 |
| Festival track | 75 |
| Chart potential | 85 |

### Best Practices

1. **Build Momentum**: Start with lower quality releases to build fans
2. **Quality Over Quantity**: High quality releases perform better long-term
3. **Match Trends**: Align releases with current world trends
4. **Genre Consistency**: Stick to your core genre for label deals

---

## Tips for High Quality Tracks

### Production Checklist

- [ ] All stats above 70
- [ ] Gear optimized for genre
- [ ] Burnout below 50%
- [ ] Matching current trends
- [ ] Label requirements met (if signed)

### Common Mistakes

1. **Ignoring Mixing** - Often the easiest stat to boost
2. **Neglecting Gear** - Free quality is always available
3. **High Burnout** - Destroys track quality
4. **Anti-Genre Stats** - Wrong BPM range hurts everything
