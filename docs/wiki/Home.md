## Stats & Progression

### Core Statistics

| Stat | Description | How to Increase |
|------|-------------|-----------------|
| **Fans** | Your follower base | Releases, gigs, social media |
| **Hype** | Current buzz (decays over time) | Performances, releases, tours |
| **Prestige** | Overall career standing | Successful releases, labels, festivals |
| **Cash** | Currency for purchases | Gig payouts, royalties |
| **Inspiration** | Creative energy | Rest, positive events, breakthroughs |
| **Burnout** | Exhaustion level | Overwork decreases it; rest increases |

### Stat Interactions

- **High Burnout** → Lower track quality, worse gig performance
- **High Hype** → Better gig payouts, more label interest
- **High Prestige** → Access to bigger venues and labels
- **High Fans** → Wider release reach, faster career growth

## Track Creation

### DAW Track Creator

Create tracks with the following parameters:

| Parameter | Range | Effect |
|-----------|-------|--------|
| **Genre** | 16 genres | Determines target audience and venues |
| **BPM** | Genre-specific | Affects energy and danceability |
| **Energy** | 1-100 | High energy = better for festivals |
| **Groove** | 1-100 | Affects catchiness and replay value |
| **Sound Design** | 1-100 | Technical quality of the production |
| **Mixing** | 1-100 | Professional polish (needs good gear) |
| **Originality** | 1-100 | Unique sound signature |
| **Catchiness** | 1-100 | How memorable the track is |
| **Danceability** | 1-100 | Club readiness |
| **Complexity** | 1-100 | Technical depth |

### Stems System

Each track has 5 customizable stems:
1. **Beat** - Drums and percussion
2. **Bass** - Low-end elements
3. **Synth** - Melodic content
4. **FX** - Sound effects and transitions
5. **Vocals** - Vocal elements (if any)

### Track Quality Calculation

Track quality = weighted average of all parameters, modified by:
- Current gear level (better gear = better mixing)
- Skill tree upgrades
- Burnout level (high burnout = lower quality)
- Inspiration level (high inspiration = better quality)

## Releasing Music

### Release Options

#### Independent Release
- **Cost**: Free
- **Payout**: 100% royalties (minus platform fees)
- **Reach**: Based on fans and hype
- **Speed**: Immediate release

#### Label Release
- **Cost**: None (label pays you)
- **Advance**: One-time payment based on label tier
- **Royalty Split**: Varies by label (70/30 to 40/60)
- **Promotion**: Label provides marketing support

### Release Performance Factors

1. **Genre Trends** - Match current world trends for bonus plays
2. **Your Hype** - Higher hype = more visibility
3. **Your Fans** - Larger base = more initial plays
4. **Track Quality** - Better tracks get recommended more
5. **Label Support** - Signed tracks get promotion boosts

### Release Formats

| Format | Audience Size | Pay Per Play |
|--------|---------------|--------------|
| Digital Single | Medium | Low |
| Vinyl EP | Small (underground) | Medium |
| CD Single | Medium | Low |
| Web Album | Large | Very Low |
| Cassette | Small | Medium |

### Gig Requirements

- **Minimum Prestige** - Must have enough standing to play venue
- **Genre Match** - Playing preferred genre improves performance
- **Gear Level** - Better gear = better equipment for shows

### Gig Payout Calculation

Base payout × (1 + prestige bonus) × (1 + hype bonus) - travel cost = net profit

### Performance Quality

Affects reputation gained from gig:
- Track your gear level
- Match the venue's genre preference
- Your current burnout level
- Skill tree performance upgrades

## World Trends

### Trend System

Every few game months, world trends rotate affecting:
- **Genre Popularity** - Some genres get more plays
- **Hype Multipliers** - Trendy genres get 1.5x-2x plays
- **Label Interest** - Labels seek specific genres during trends

### Trend Types

| Trend | Effect | Duration |
|-------|--------|----------|
| **Techno Revival** | Underground techno +50% plays | 2 months |
| **Trance Summer** | Trance +40% plays | 1 month |
| **House Renaissance** | House +35% plays | 2 months |
| **DnB Awakening** | Drum & Bass +45% plays | 1 month |
| **Synthwave Wave** | Synthwave +60% plays | 3 months |

### Leveraging Trends

1. Release tracks in trending genres during their peak
2. Book gigs in cities that boost trending genres
3. Focus skill upgrades on trending genre bonuses

## Career Archetypes

### Early Game Strategy

1. **Build Fan Base**: Release frequently, build following
2. **Experiment**: Try secondary genres for originality bonuses
3. **Save for Gear**: Prioritize studio headphones ($190)
4. **Manage Burnout**: Rest between intense production periods

### Mid Game Strategy

1. **Target Labels**: Sign with labels matching your genre/prestige
2. **Tour Wisely**: Build hype before major releases
3. **Skill Focus**: Invest in skill upgrades for long-term advantages

### Late Game Strategy

1. **Festival Circuit**: Target major venues for maximum payouts
2. **Balance Burnout**: Strategic rest periods
3. **Master Trends**: Ride hype multipliers for explosive growth

## Game Systems

### Time Progression

- **Week**: Basic time unit
- **Month**: 4 weeks = 1 month
- **Year**: 12 months = 1 year

Each "Next Week" advances time and triggers:
- AI scene simulation (other artists releasing/ touring)
- Label activities
- Trend updates (monthly)
- Fan/hype decay

### Save System

- **Auto-save**: Game state saved after every action
- **Save Slots**: 3 manual save slots for multiple careers
- **Export/Import**: Backup career to JSON file
- **Cloud Sync**: Uses localStorage (browser-based)

### Burnout Management

| Burnout Level | Effect |
|---------------|--------|
| 0-25% | Normal operation |
| 26-50% | -10% track quality |
| 51-75% | -25% track quality, -10% gig rating |
| 76-100% | -40% track quality, -25% gig rating |

**Recovery Methods**:
- Take a week off (-15% burnout)
- Vacation (skip 2 weeks, -30% burnout)
- Inspiration boost events

## Tips & Tricks

### Maximizing Revenue

1. **Release Timing**: Align releases with world trends
2. **Label Negotiation**: Wait for higher prestige before signing
3. **Gig Efficiency**: Visit multiple nearby cities per tour
4. **Gear Synergy**: Match gear purchases to your genre focus

### Building Fans Fast

1. **Social Drama**: Participate in forum events for visibility
2. **Consistent Release Schedule**: New music weekly initially
3. **Genre Experiments**: Try trending genres for quick boosts
4. **Gig Frequency**: Perform regularly in high-traffic cities

### Efficiency Tips

- Save before major decisions (signing labels, big purchases)
- Use save slots for experimental strategies
- Export backups before updates
- Monitor burnout constantly - it's your biggest limiter
