# 🎵 Beatmaker Legend

## Electronic Music Career Simulator

**Beatmaker Legend** is a comprehensive career simulator where you rise from an unknown bedroom producer to an electronic music icon. Navigate the complex world of synth programming, underground scenes, record labels, and global touring—all from your suburban bedroom.

---

## 🎮 Game Overview

### The Story
You start as a bedroom producer with an old laptop, basic DAW, and stock earbuds. Your mission: carve your path through the global electronic music underground, build a loyal following, sign with legendary labels, perform at iconic venues, and become a beatmaking legend.

### Core Gameplay Loop
- **Compose Tracks** — Use the DAW Track Creator to design unique tracks with BPM, energy, groove, and experimental factors
- **Release Music** — Choose between independent releases or signing with record labels
- **Book Gigs** — Travel to cities worldwide and perform at venues matching your prestige
- **Upgrade Gear** — Invest in hardware synths, studio equipment, and acoustic treatment
- **Develop Skills** — Level up production, engineering, performance, and marketing abilities
- **Track Trends** — Navigate the ever-changing world music trends to maximize impact

## 📊 Stats Explained

| Stat | Description | Affects |
|------|-------------|---------|
| **Fans** | Your follower base | Release reach, label requirements |
| **Hype** | Current buzz level (decays) | Gig payouts, trend visibility |
| **Prestige** | Overall career standing | Venue access, label interest |
| **Money** | Currency for upgrades | Gear, travel, skills |
| **Inspiration** | Creative energy | Track quality potential |
| **Burnout** | Exhaustion level | Track quality, gig performance |
| **Skill Points** | Unlocks skill upgrades | Skill tree progression |

## 🎯 Tips for Success

### Early Game
1. Focus on building fans through frequent independent releases
2. Experiment with secondary genres for originality bonuses
3. Save for studio headphones ($190) to boost mixing quality

### Mid Game
1. Target appropriate labels matching your genre and prestige
2. Use tour stops to build hype before major releases
3. Invest in skill upgrades for lasting production advantages

### Late Game
1. Pursue festival-level venues for maximum payouts
2. Balance burnout through strategic rest periods
3. Master trending genres to ride hype multipliers

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Gemini API Key

### Installation
```bash
npm install
```

### Configuration
Create a `.env.local` file with your API key:
```
GEMINI_API_KEY=your_api_key_here
```

### Run the Game
```bash
npm run dev
```

Access the game at `http://localhost:3000`

## 🎮 Quick Reference

### Keyboard Shortcuts
- Save game automatically every action
- Use save slots (1, 2, 3) for multiple careers

### Game Mechanics
- **World Trends**: Rotate every few months, boosting specific genres
- **Hype Decay**: Needs constant releases or performances to maintain
- **Burnout**: Track quality drops when burnout is high
- **Label Deals**: Require minimum fans and hype thresholds
